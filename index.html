    つくる、撮る、学ぶ。

    Learn languages through the anime, comics and games you already love.

    VANT builds AI tools for fans who would rather learn from a manga panel than a textbook: a Discord companion, a speaking tutor and a story-driven RPG.

    It is a joint project of Vibra, which keeps every tool simple, and AnTiMa, the anime-and-AI side that builds them.

    いい作品は、好きなものから始まる。 Learning a language shouldn’t feel like homework.

    アニメと語学から始まり、あらゆる創作の場所になった。 VANT is for people who would rather learn Japanese from a manga panel than a textbook drill.

    写真、アプリ、実験、講座。心を込めて作ったものなら、ここにある。 So we build tools inside the anime, comics and games world fans already love, where practice feels like play.

    What every release has to pass

    1. FunIf it isn’t enjoyable, it isn’t finished.
    2. AccessibleEasy to start and hassle-free, for any learner.
    3. TechnologyModern AI does the heavy lifting so learning feels natural.
    4. CommunityBuilt for fan spaces like Discord, where people already learn together.
